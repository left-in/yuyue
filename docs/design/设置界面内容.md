# 语阅 Mac 设置界面：内容清单

给重新设计原型、交互和 UI 用。这里只列**设置里有什么**，不规定怎么摆。内容取自现在的 App 代码（`apple/Yuyue/App/MacSettings.swift`、`MacCompanionSettings.swift`、`MacForeignSettings.swift`、`MacSyncSettings.swift`、`Library/MacPodcastView.swift`），2026-11-03。

## 先知道的几件事

- **打开方式**：⌘, 打开，是一个单独的窗口。
- **现在的结构**：顶上一排 10 个分页（通用、外观、阅读、播客、朗读、外文、书伴、同步、存储、数据），每页一列设置。
- **和读书窗口的关系**：读书窗口右上角的 **Aa** 里也能改纸色、字体、字号、行距、翻页。设置里改的是**所有书的默认**；某一本书在 Aa 里另外改，只影响那一本。语速也是同一个值，两边改的是同一个。
- **外观**：要支持浅色、深色、跟随系统。主题色有两种：墨蓝（默认）、墨黑。按钮、开关、进度和选中都用主题色。
- **语言**：界面要能放下英文翻译（英文通常比中文长）。
- **Key 和隐私**：书伴、云端声音、Notion、flomo 这些都是用户自己的 Key 或令牌，只存在这台 Mac 的钥匙串里，语阅不经手、不收费。
- **常用程度**（估计）：最常改的是阅读（纸、字、字号、行距）、朗读（声音、语速）、书伴（连 Key）。同步、存储、数据一般设一次就不再动。

## 1. 通用

| 项 | 控件 | 说明 |
|---|---|---|
| 打开语阅时接着读上次那本 | 开关 | 关掉就只打开书架 |
| 听书时 Mac 不睡着 | 开关 | 合上盖子照样会停 |
| **导入** | | |
| 把书拖进书架窗口就导入 | 只是说明，没有控件 | 支持 EPUB、PDF、MOBI、AZW3、TXT；会拷一份进语阅，原文件挪走、删掉都不影响 |

## 2. 外观

| 项 | 控件 | 说明 |
|---|---|---|
| 界面 | 三选一（浅色 / 深色 / 跟随系统），带缩略图 | 管书架、设置这些窗口；书页的纸色在读书窗口的 Aa 里另选 |
| 主题色 | 二选一（墨蓝 / 墨黑），圆形色块 | 墨蓝是默认；按钮、开关、进度和选中都用这个颜色 |
| 看看效果 | 只是演示 | 一个“接着读”按钮、一条 62% 的进度、一个开关、一个“全部”标签，用来看主题色的效果 |
| 书架封面大小 | 滑杆 | 窗口越宽，一排放得越多 |
| 封面下面写进度 | 开关 | 关掉只留书名 |
| 液态玻璃效果 | 开关（仅新系统才有） | 读书窗口里浮着的胶囊、提示条用系统的液态玻璃；关掉用毛玻璃 |

## 4. 播客

现在只是一页说明，真正配置在书架窗口左边的“播客”里。

| 项 | 控件 | 说明 |
|---|---|---|
| 节目 | 只是说明 | 在书架窗口左边的“播客”里配节目、写新一集 |
| 写稿用的模型 | 只是说明 | 和书伴用同一个：设置 › 书伴 |
| 主持人的声音 | 只是说明 | 每台设备自己选，在配节目的“谁来讲”里试听 |
| 听过的节目一直保留 | 开关 | 关着时，听完 30 天的节目自动清掉；划过线、加过书签的留着 |

> 设计时可以考虑：这一页要不要单独存在，还是并进“朗读”或拿掉。

## 5. 朗读

| 项 | 控件 | 说明 |
|---|---|---|
| 语速 | 滑杆 + 数字（如 1.2×） | 读书窗口里调的也是这一个 |
| **声音** | | |
| 中文 | 选一个声音 + “试听”按钮 | 试听念“从前有一座山，山里有一座庙。” |
| 英文 | 选一个声音 + “试听”按钮 | 试听念 “It was the best of times…” |
| 说明 | 文字 | 系统声音在这台 Mac 上合成，不联网。想要更自然：系统设置 › 辅助功能 › 朗读内容 › 管理声音，下载“高级”的那几个 |
| **云端声音** | | |
| OpenAI | 输入 Key + “连接” | 连上后显示“已连上 · N 个声音” |

| ElevenLabs | 输入 Key + “连接” | 同上 |

## 7. 书伴（AI）

| 项 | 控件 | 说明 |
|---|---|---|
| 服务商 | 下拉选择 + “添加服务商…” | 可以是这台 Mac 自带的（Apple，不联网、不用 Key），也可以加 Claude、OpenAI 等，填自己的 Key |
| 模型 | 下拉选择 | 加载时显示“正在问它有哪些模型…” |

> 这里的模型也给播客写稿用。连 Key 是用户最容易卡住的一步：要考虑怎么拿 Key、粘贴后自动识别是哪家、怎么提示出错。

## 还没有、但可以考虑的

- **关于**：现在没有单独的“关于”页。可以放 App 图标、版本、检查更新、写信给我们、隐私说明。
- **搜索**：现在设置里不能搜。10 页、几十项设置，加一个搜索会好找很多。
- **改回默认**：现在没有“全部改回”，也看不出哪些改过。
- **分页整理**：10 个分页偏多。播客只是说明；存储和数据都偏“数据”。设计时可以考虑重新分组。

## 交互和状态要覆盖

- 改了马上生效，不需要“保存”。
- 填 Key / 令牌的地方：空、正在检查、成功、失败（原因写清楚）、清掉。
- 正在进行的操作（导入词典、生成快照、同步、下载翻译）：进度、完成、失败。
- 会删数据的操作（清掉已删除的书、删快照、清掉存下的回答）：要能撤销或二次确认。
- 键盘：⌘, 打开，⌘W 关；能用 Tab 和方向键走完所有控件。
- 浅色、深色、两种主题色下都要好看。
