书伴 · 朗读 · 笔记导出

选模型：书伴点一家 → 右栏“模型”一行 → 右栏换成能搜的列表：在用、最近用过、推荐、全部，打字筛、回车选第一个、没有的名字也能用。朗读（新）：搜索没有框，只一条细线；下面一排“听起来”的词（女声、男声、讲故事、温柔…），点一下就筛、再点取消，可以叠着用。声音两列、只写名字和风格。指着就在右栏读；把指针挪到右栏也不会丢，右栏有一行“用它读中文”。键盘 ← → ↑ ↓ 在两列里走，回车换上。

朗读：指着声音听 → 点一下换上；直接打字就是搜（“粤语”“讲故事”）；↑↓ 一个个听，回车换上，⌘Z 改回；分组标题右边“Key 和连接”看那一家的 Key。右栏“换一句”可以自己写一句。最近改过：右上角的钟。

选声音：照 Mac 系统设置

系统设置 › 辅助功能 › 朗读内容 › “系统声音”就是这样：一行，右边当前的声音 ⌃⌄，点开是菜单。大家都用过，不用学。

少了什么

  • 没有右栏那张卡、没有带侧栏的大弹窗、没有先挑分类那一步。
  • 原来 3–4 步（点行 → 点卡 → 挑分类 → 指着听 → 点），现在 2 步：点行 → 点声音。
  • 平时页面上只有两行，干净；在用谁写在行尾，不用点开就知道。

声音和模型不一样的地方

  • 按耳朵分：推荐在最上面，女声 / 男声 / 童声 / 方言是子菜单，每个后面写有几个；在用的那组打勾。
  • 指着就听：右栏“试听”马上用它读《故乡》那一句，标着“还没换”；挪开就回到在用的。
  • 哪家的只是行尾一个小 logo；没连的服务商在菜单最底下“连上 ElevenLabs…”。
  • 换错了：右栏“改回 婷婷（高级）”或 ⌘Z。

声音很多怎么办（上一版）

Azure 一家就有几百个，ElevenLabs 更多。按“从哪来”分没用，人是按“听起来什么样”挑的。

点一下就听、就用它

  • 像 iPhone 选铃声：点哪个声音，就用哪个读那一句，同时它就成了“读中文”的声音。没有单选圈，也没有单独的 ▶ 圆钮。
  • 不满意点下一个；想回到原来的，右上角的钟里撤销，或 ⌘Z。
  • 最上面一张卡是现在在用的：名字、什么声音、哪家的，下面就是它读的那句；点右边的声纹再听一次。原来的“试听”并进了这张卡。

几百个也挑得动

  • 先按听感筛：女声 / 男声 / 童声；搜“粤语”“讲故事”“播音”“台湾腔”都行。
  • 两列小方块，一屏能看十几个；每块右上角一个小 logo 说是哪家的。
  • 每家先给 6 个，“再看 N 个”才全展开，几百个也不会一下子铺满。

最近改过

不再常驻右栏。右上角“已存在这台 Mac”旁边一个钟，带今天改了几次的数字；点开是贴着它的一张小卡，点外面或 Esc 就收起；⌘Z 照样撤销最近一条。

模型很多怎么办

不用单选圈。设置里模型只占一行；点进去是一个能搜的列表。

没打字的时候

  • 最近用过：换来换去的那两三个，排最上面。
  • 推荐：三个，每个一句人话——最聪明 / 平时就用它 / 快又便宜，不用看 id 猜。
  • 全部 N 个：多的时候按厂商分组，每组带它的 logo 和数量（OpenRouter 40 多个也翻得动）。
  • 在用的那个打勾、整行淡蓝；点别的一行就换，右栏回到服务商设置。

打字的时候

  • 搜名字或 id 都行，“flash”“qwen”“4.5”，命中的字标蓝。
  • 回车选第一个，第一个有一圈框提示。
  • 没找到：最后一行“用‘xxx’这个名字”，新出的模型不用等语阅更新。
  • 列表只在你点“模型”这一行时出现，平时设置里只看到一行“模型 · Claude Opus 5.5 ›”。

这一版改了什么

你说按钮和输入框不喜欢、要真 logo。

按钮 → 行

  • “打开 flomo 的 API 页”：不是胶囊按钮了，是步骤里的一行，左边 1、2 的序号，右边 ↗，整行可点。
  • “连接”：没有了。填进去的东西一像样，就自己去试，一项一项打勾，最后一条绿横幅。
  • “取消”：没有了。不想连就去点中间别的一行。
  • “用这个”：变成一行开关“书伴用它”，和中间的“在用”是同一件事。
  • “检查”：一行“检查连接”，结果写在这一行右边（● 2.1 秒）。
  • “断开 / 移除”：最下面单独一组里的一行红字，和别的分开，不会误点。

输入框 → 行里打字

  • 左边写这一行是什么（Key、API 链接、放书的那一页），字直接打在右边，没有圆框、不用等宽大字；点进去整行淡淡变蓝。
  • Key 存过以后只露尾巴（sk-ant-••••3fa），点这一行就能重打。
  • 错了：整行变淡红，下面一句为什么。
  • 剪贴板：Mac 上拷了一个像 Key / 像 flomo 链接的东西，回到设置会多出一行“用剪贴板里的 …”，点一下就填好、自己去连。

logo

  • Claude、OpenAI、DeepSeek、Gemini、Kimi、通义、Ollama 用 App 里已经有的那套（lobehub icons），这里用彩色版。
  • Obsidian、Notion、ElevenLabs 来自 Simple Icons；Azure 来自 lobehub；flomo 用它官网的图标。
  • 都放在白底小方块里（像系统设置里的 App 图标），深色模式也是白底，品牌色不变。
  • 原型用的文件在 docs/design/logos/；做进 App 时放进 Assets 里，和现在的 provider-* 一起。
