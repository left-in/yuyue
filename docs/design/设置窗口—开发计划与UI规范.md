# 语阅 · 设置窗口 —— 完整开发计划与 UI 规范

> 2026 年 11 月 3 日。照《windowScene —完整产品开发计划与 UI规范》的写法。本篇只写“怎么造出来”：分几步做、每步做什么不做什么、会出什么事、状态怎么走、尺寸颜色动效是多少。
> 现在的设置有哪些内容，逐项列在最后的**附录**里，数字都取自现在 Mac App 的代码（`apple/Yuyue/App/MacSettings.swift` 等，`apple/Yuyue/Design/Tokens.swift`）。

## 一、先说几件事（不纠缠）

1. **名字撞了**：SwiftUI 自带一个 `Settings` 场景。代码里不要用 `Settings` 做类型名，用 `MacSettings` / `SettingsPage`；“设置”只是界面上的名字。
2. **两处改同一件事**：读书窗口右上角的 **Aa** 也能改纸色、字体、字号、行距、翻页。规则写死：**设置里改的是所有书的默认，Aa 里改的只是这一本**。语速例外，两边是同一个值。设计里每一处都要让人看得出“这是默认”还是“这是这本书”。
3. **Key 都是用户自己的**：书伴、云端声音、Notion、flomo 的 Key 或令牌只存在这台 Mac 的钥匙串里，费用走用户自己的账号，语阅不经手。界面上要说清楚这一点，但只说一次。
4. **现在有 10 个分页**（通用、外观、阅读、播客、朗读、外文、书伴、同步、存储、数据），偏多：播客页只有说明；存储和数据都是“数据”。重新分组是 S0 要定的事。

### 阶段划分与目标

| 阶段 | 时长 | 唯一目标 | 交付 |
|---|---|---|---|

| S1 常用三页 | 1 周 | 最常改的三件事（纸和字、声音、连书伴）变顺手 | 新窗口框架 + 阅读、朗读、书伴三页 |
| S2 其余搬过来 | 1 周 | 其余各页搬进新框架，一样不少 | 外观、通用、外文、同步、存储、数据、关于 |
| S3 找得到、改得回 | 1 周 | 能搜、看得出改过什么、能改回默认；所有状态做全 | 搜索、改过的标记、改回默认、空态、出错 |

### S0：决定（必须先做，别跳）

三个问题，答案写进一页纸，后面照着做：

1. **怎么分组？** 建议从 10 页并成 7–8 页：播客并进“朗读”或拿掉；存储和数据合成“数据”；加一页“关于”。
2. **哪几页有预览？** 只给改了要“看一眼才知道”的：阅读（纸、字、字号、行距）、朗读（试听）、外文（难词注释）。其余页不放预览，设置占满。
3. **做不做搜索？** 建议做。几十项设置分在七八页里，搜索是找东西最快的路。

### S1：常用三页（MVP 边界写死）

**做**：
- 新的窗口框架：导航 + 内容区（+ 预览区，只在需要的页出现）
- 阅读：纸色、字体、字号、行距、翻页、两栏、对齐、缩进、标点挤压；沉浸阅读那一组；改了预览马上变
- 朗读：语速、中英文声音各带“试听”、三家云端声音的 Key
- 书伴：服务商、模型、测试一下；**粘贴 Key 自动认出是哪家**

**不做**：其余各页（先保留旧的）、搜索、改回默认、关于页、动效打磨。

**验证指标**：
- 改纸色、改字号：打开设置后 1 次点击就到，2 次操作内完成
- 连上书伴：从“我有一个 Key”到“连上了”不超过 3 步
- 自己用满 7 天，不再回 Aa 以外的地方找这几样

### S2：其余搬过来

- 外观、通用、外文（含 MDict 词典列表、往上挪/往下挪/移除）、同步（三种方式、WebDAV 表单、设备列表）、存储（用量条、清掉、每本书从大到小）、数据（笔记导出、快照、阅读记录）
- 新增“关于”：App 图标、版本、检查更新、写信给我们、隐私说明
- 每一页搬完，对着附录逐项打勾，**一样不能少**

### S3：找得到、改得回

- 搜索：⌘F，搜的是每一项设置（名字 + 说明 + 同义词），回车跳到那一行并亮一下
- 改过的标记：导航上，有改动的页名旁边一个小点
- 改回默认：每一项、每一页、全部，三级都有；改回之后能撤销一次
- 所有异步操作的状态做全（见 4.1），所有空态做全（见 4.3）

### S4：打磨验收

- 浅色 / 深色 × 墨蓝 / 墨黑，四种组合截图检查
- 英文界面：最长的标签放得下，不截断、不换成三行
- 键盘：Tab 能走完所有控件，⌘F、⌘1–9 可用（见第六节）
- 系统“减弱动态效果”打开时，动效按 5.4 退化
- 小字（10.5–11.5 号）的对比度达标

## 三、风险清单（按致命程度排）

1. **Aa 和设置两处改，用户不知道哪个生效。** → 设置里每个书页相关项的说明写“所有书的默认”；Aa 里，如果这本书和默认不同，显示“这本书单独设了 · 改回默认”。
2. **连 Key 失败。** 这是用户最容易卡住的一步。→ 粘贴就自动认出是哪家；核对时显示“正在核对”；失败写清原因（Key 不对、没网、额度用完）；旁边给“去哪里拿 Key”的链接。
3. **误删数据。** 清掉已删除的书、删快照、清掉存下的回答都会删东西。→ 能撤销的给“撤销”（几秒内）；不能撤销的才弹确认。
4. **换同步方式出冲突。** 从 iCloud 换到 WebDAV 时两边数据可能不一致。→ 换之前一句话说明会发生什么；冲突走现有的冲突表单，不自己造新流程。
5. **页数越加越多。** → 以后每加一项，先回答“放进哪一组”；一页超过约 12 行就考虑拆。
6. **英文撑破布局。** → 标签宽度不写死；控件放不下时换到下一行。

## 四、关键设计细节

### 4.1 状态机

**普通设置项**（开关、分段、滑杆）只有两个状态：

```
默认 ⇄ 改过
```

- 改了立刻生效，没有“保存”
- 改过的项能“改回默认”；改回后几秒内可以撤销

**要连接的项**（书伴服务商、云端声音、Notion、flomo、WebDAV、Google Drive）：

```
空 → 核对中 → 已连上
         ↘ 失败（写原因）→ 重填
已连上 → 清掉 / 断开 → 空
```

- “核对中”必须有转圈和文字，最长 10 秒，超时算失败
- “已连上”显示能确认的信息（Key 末四位、“N 个声音”、账号）

**要下载、导入、生成的项**（离线翻译、MDict 词典、快照、同步）：

```
没有 → 进行中（进度）→ 可用
            ↘ 失败（写原因 + 重试）
```

### 4.2 预览

- 只在阅读、朗读、外文三页出现，放在内容旁边，和第一组设置顶部对齐
- 阅读：一页书，照现在的纸、字体、字号、行距、对齐、缩进排，改了马上变
- 朗读：试听按钮就是预览；可选：一段文字念到哪亮到哪
- 外文：一小段英文，难词上方写中文，换级别时标出来的词跟着变
- 其余页**不放预览**，设置占满

### 4.3 空态

每个空态一句话 + 一个按钮，不放教程：

| 地方 | 一句话 | 按钮 |
|---|---|---|
| 书伴没连任何服务商 | 现在用这台 Mac 回答，不联网。连上一家云端 AI 会讲得更细。 | 粘贴 Key |
| 云端声音都没连 | 系统声音就能用。想要更像真人的声音，填一个 Key。 | 粘贴 Key |
| 没设同步 | 只在这台 Mac 上。选一种方式，几台设备之间就跟着走。 | 三张方式卡片 |
| 没有 MDict 词典 | 没有导入的词典时，用 Mac 自带的。 | 导入 MDict 词典 |
| 没有快照 | 快照能把进度、笔记、生词带到另一台设备。 | 生成快照 |
| 搜索没结果 | 没有“××”。试试 字号、Key、备份。 | — |

### 4.4 改回默认

- 三级：单项（行内“改回默认”）、整页（页底）、全部（导航底部）
- 导航上，有改动的页名旁边一个小点；全都是默认时不显示任何东西
- “全部改回”不动 Key、同步账号、导入的词典这些“连接类”内容

### 4.5 搜索

- ⌘F 聚焦搜索框；搜每一项设置的名字、说明和同义词（比如“暗”能找到深色和夜间纸）
- 结果写“设置名 · 在哪一页”；上下键选，回车跳过去，那一行亮一下（1.6 秒淡掉）
- Esc 清空并收起

### 5.4 动效参数

| 动作 | 时长 | 曲线 |
|---|---|---|
| 悬停、按下、开关拨动 | 0.14 秒 | ease-out |
| 换页、展开收起、选中滑过去 | 0.24 秒 | spring，不回弹 |
| 布局变化（预览出现/消失、列表增删） | 0.35 秒 | spring，不回弹 |
| 消失 | 0.12 秒 | ease-in |
| 搜到后那一行亮一下 | 1.6 秒 | 先亮后淡 |

**减弱动态效果**打开时：全部退化为 0.1–0.15 秒的纯不透明度变化，去掉位移和弹性；布局变化不做动画。

### 5.5 四条禁令

1. **不弹二级窗口。** 填 Key、WebDAV 表单都在那一行底下原地展开；只有系统自己的面板（选文件夹、登录 Google）例外。
2. **不只靠颜色表示状态。** 成功、失败、改过都要配文字或图标。
3. **不做“保存”按钮。** 改了就生效，靠撤销和改回默认兜底。
4. **不在设置里放单本书的设置。** 单本书的事只在读书窗口的 Aa 里。

## 七、交给 AI 做的策略

不要一次把整份丢给 AI，它会给你一个每样都做了 30% 的东西。**按阶段拆，每次只给一个模块 + 上一阶段的产出，并写明这一包不做的事。**
