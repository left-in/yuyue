语阅 Mac 首页：三个方向

只看 Mac 的“全部”页。下面每个方向都是同一批书，左边是窗口样子，右边是它想解决什么。选一个，或者说“A 的上半部分 + C 的那一行”这样混着要。最后一节是漫画图标第三轮。

和读书页不是一家读书页是纸色、宋体、蓝色按钮；首页是灰底、白卡、黑按钮。点进书像换了个 App。
没有主角三张一样大的卡片加一排小封面，眼睛不知道先看哪。
封面又小又平封面是读书 App 最好看的东西，现在缩成方块，没有书的厚度。
