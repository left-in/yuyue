Mac 首页导航 · 换样式

里面放什么不动：搜索 · 问、资料库（全部 / 书 / 漫画 / 有声）、状态（在读 / 想读 / 读完）、笔记（笔记 / 生词本）、合集、底下的同步。只换它的样子，让导航和书架不再挤成一块。每种都是原大的书架窗口，右边的书一模一样，只有导航不同。上面可以切深色看。

现在难看在哪：导航是一张浅灰的卡片，书架是灰底，两块灰只差一点点，卡片的边又和“在读”卡片、选中那行的白卡长得一样，眼睛分不出哪块是导航、哪块是内容，像一堆卡片堆在一起。

放在这里对照。

推荐A · 书桌上放一张纸

导航没有卡片，直接写在书桌上（比书架深一档的暖灰），书架是一整张纸，四边离窗口 8，圆角、淡淡的影子，像从桌上拿起来的一页。两块之间一眼分开：一边是桌面、一边是纸，不再是两张差不多的卡。选中那行只垫一层淡灰，不再用白卡（白卡留给书架里的东西），同步上面的线也去掉。和读书窗口“纸铺满整窗”是同一个说法。

B · 一块玻璃浮在书上面

导航是一整块毛玻璃，大圆角，浮在书架上；书架从玻璃底下一直铺到窗口左边，封面在玻璃后面透出颜色。搜索框和选中那行都是胶囊，和 iPhone 的玻璃底栏、播放条一家（你定过 iPhone 用 iOS 26 的玻璃）。缺点：玻璃后面是什么颜色导航就跟着变，书少的时候几乎看不出玻璃。

C · 书脊

导航是一条深墨蓝的布面书脊，贴满窗口左边，字是白的；右边书架是纸色。颜色差最大，导航和内容永远不会混。墨蓝就是主题色，深色模式下暗一档。缺点：最“有个性”，窗口里一大块深色，看久了会比 A 重。

D · 一条图标栏 + 标题旁的筛选

导航收成左边 78 宽的一条，只放四个地方：书架、笔记、生词本、合集。书 / 漫画 / 有声、在读 / 想读 / 读完 挪到标题下面一排胶囊（内容还是那些，只是换了位置）。合集多，鼠标停在“合集”上从旁边弹出列表，书也能拖上去。书架最宽；缺点是改动最大，资料库和状态不再常驻左边。
