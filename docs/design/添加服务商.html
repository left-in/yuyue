名片 A

在用的那个是一张名片：标识、模型、快不快，再放一句它刚才答过的话，让人知道接上的是什么。换一个是下面一排小卡片；添加是一面标识墙，点开那家就进它自己的一页，只问一件事：Key。

试试：· 点「＋ 添加」，选 Claude 粘贴任意 Key；或在墙上的搜索框粘贴 sk-or-v1-…

一句话 B

整页就一句话：「书伴现在用 Claude 的 opus」，两个词都能点开换。下面一个框，什么都往里放：Key、地址、名字。它自己认：sk-ant- 是 Claude，http://192.168…:11434 是 Ollama，magpie 就找本机的 magpie；认出来当场验证，回车就接上。没有设置表单。

三条路 C

读书的人不一定懂 API。先问想怎么用，三张卡：免费（这台 Mac 自带、本机的 Ollama）、用我已有的账号（OpenRouter 登录、magpie 转接 Claude / ChatGPT 会员）、我有 Key（粘贴就认，列表只是备用）。每条路只给它自己的那一两步，花不花钱写在卡片底下。

试试：· 点「用我已有的账号」→ 用 OpenRouter 登录；或「我有 Key」粘贴 AIza…

怎么选

三套共用同一份数据和验证；差在从哪儿开始。
