第二十一版：照 Kanso 的设计理念 11-03

从 Kanso 学的不是样子，是想法：整扇窗是一张纸，没有侧栏面板、没有卡片，只靠留白和细线分开；先用一个大字和一句人话说现在是什么样，再给你列表；只有墨色和纸色，主按钮是实心黑；数据本身就是画面。放到语阅：窗口就是你选的纸（选夜间纸，整扇窗就是夜里）；左边目录只是一列字；中间每页开头一个大字和一句话（“15 号 · 宋体，行距 2.0，印在纸本上”），改什么这句话跟着变；右边是这一页的图——书页、外文、声音是直接排在窗口纸上的那一页，存储是一张块状图（空着的地方是一圈圈的线），同步是三台设备；别的页没有图，列表变宽。

第二十版：同一个方案，五种样子 11-03

方案不动：左边一张纸是目录，右边一张纸是设置和预览。只换样子，底下的黑色切换条点名字或按 1–5、← → 换。素纸：白纸、只有细线、没有影子，目录无衬线，选中只点一个小圆点。书卷：暖纸、几乎方角、衬线，目录有编号、章名后一道线，设置是有线的列表、不用卡片。墨封：目录是一张墨蓝的封面纸、浅色字，右边白纸、设置是浅灰的凹槽。留白：大圆角、大字、很多空，目录不写章名和页码，选中只靠深浅。格线：单色、方角、01 02 编号、拉开字距的小标题和直线，选中的后面一个箭头。

第十九版：两张纸 11-03

窗口底下是稍深一点的桌面，上面并排放两张纸：左边一张是目录，右边一张是设置和预览（预览保持第十八版的样子）。两张纸一样的颜色、圆角和影子。目录不再是导航栏的样子——没有图标、没有白底块：衬线字的“目录”和一道细线，章名小字，页名和页码，选中的那一项变成墨蓝，左边页边上一道短竖线。搜索是“目录”旁边的放大镜，点开后这一行变成一条只有下划线的输入行。

第十八版：侧栏和预览重做 11-03

结构不变，改两处你圈的。侧栏改成和书架窗口一模一样：灰色分组标题单独一行，每页一个单色图标，28 高的行，选中是白底。预览不再单独漂在一边：标题和说明横跨整宽，下面设置和预览从同一条线开始，“预览”和“纸”一样是分组标题，书页装在和设置一样的白色圆角卡片里。

第十七版：普通大小的设置窗口 11-03

不做书、不做玻璃，回到一个正常大小（860 × 580）的 Mac 设置窗口。左边是书架窗口那块侧栏：“设置”和一颗放大镜，下面按 读、听、帮手、数据、其他 分好的页。中间是设置。只有书页、外文、声音三页，右边放一张真的书页（照你现在的纸、字、行距排，底下垫着两张，像一小叠），别的页没有预览，设置占满。

第十六版：只有纸和玻璃 11-03

只留两种材质：纸和玻璃。窗口是一本对称摊开的书。一整块玻璃盖住整张左页，四边留一样宽的纸，红绿灯、目录、设置都在玻璃里，玻璃底下只有干净的纸。右页是预览，清清楚楚。目录像杂志的目录：左边一栏小字写“读、听、帮手……”，右边一栏是页名，选中的是书架窗口那种白底。搜索只是“设置”旁边一颗放大镜，点它或按 ⌘F，这一行就变成搜索框，结果出现在目录的位置。

拿掉了印在纸上的目录、半盖着的玻璃、玻璃底下的字（盖过去时右页的字会先淡出）、页码、细线、索引页。
留下的两页书、一块玻璃、玻璃跟着纸变明暗、右页的预览、App 现在的行和按钮。
可以试点放大镜或按 ⌘F 搜“字号”回车；纸色点“夜间”；去同步页看玻璃盖过书脊，再回书页。

第十五版：一本书只有两页 11-03

窗口是一本对称摊开的书，书脊在正中间。左页的页边上印着目录——就印在纸上，用书的字和墨色，跟着纸变颜色；左页其余的地方浮着一块磨砂玻璃，里面是设置。右页是预览。目录只有名字和页码：选中哪一项，它变成墨蓝，名字和页码之间画出一道细线。搜索就是书后面的索引：目录最后一项“索引 ⌘F”，打开后右页变成一张索引页——按拼音首字母排好的全部设置，两栏；打字就筛，回车跳到那一行，esc 回到预览。

两页左页：目录和设置；右页：预览。不需要预览的页，玻璃盖过书脊把两页都盖住，目录还在页边上。
目录印在纸上，不再是一块侧栏；没有底色块、图标、点线，只有名字、页码和选中时的一道线。改过的页名字后面一个小点。
可以试点目录各页看那道线画过去；按 ⌘F 或点“索引”，翻翻全部索引，再打“字”“key”，上下键加回车；纸色点“夜间”，目录也跟着变成夜里的颜色。

第十四版：整个窗口是一本摊开的书 11-03

结构不变：左边目录、中间设置、右边预览。变的是三块的关系——窗口底下铺着一本摊开的书（两页，照你现在的纸、字、行距、页边排），目录和设置是浮在书上的两块磨砂玻璃，右边那一页没被盖住，它就是预览。换纸色，整个窗口连玻璃一起变颜色；拖字号，玻璃底下的字也跟着变；换到声音页，书上念到哪亮到哪，页底下浮一颗玻璃的播放胶囊；外文页，书换成英文的，难词头上写中文。不需要预览的页（书伴、同步、存储……），玻璃滑过去把那一页也盖住，只剩书的颜色透上来。

为什么不再“隔得太开”预览不是旁边另放一张纸，而是设置本来就浮在这本书上；改什么，整扇窗都看得见。
和现在的 App 一样玻璃里面的行、开关、分段、滑杆、按钮、侧栏和搜索框都是书架窗口和设置窗口里的；颜色还是纸色加墨蓝。
可以试纸色点“夜间”“黑底”；拖字号、页边；翻页换“上下滚”；点“到了晚上换夜间纸”；去声音页、外文页；再点同步，看玻璃滑过去盖住书页。

第十三版：照书架窗口 11-03

这次照着项目里的设计规范（界面、排版、版式、配色几份）改：窗口外壳、侧栏、搜索框、行、按钮全用书架窗口和现在设置窗口里的；只有一种强调色（墨蓝）；衬线字只用在“目录”、章号和纸上。侧栏就是目录：章是“一 读、二 听……”，页码放在书架侧栏写本数的位置。搜索框和书架一样在侧栏最上面，搜的时候侧栏变成结果，回车跳到那一行。预览那一栏也用“预览”这样的分组标题开头，和设置的第一组齐平；没有预览的页，设置就占满，窗口大小不变。书伴只有一行“用云端 AI · 粘贴 Key”，剪贴板里有 Key 时这一行直接写出来，按钮变成“用它”。

和现在的 App 一样侧栏是书架窗口那块浮起来的侧栏，选中的白底、右边灰色数字、顶上的搜索框都一样；按钮是“接着读”“听”那种圆角按钮。
拿掉了点线、双线、字母间距拉开的小字、彩色的厂商方块、顶上的提示条、会变宽变窄的窗口、渐隐被裁掉的纸。
可以试点“书伴”，点“用它”；点“这台 Mac”切回来；“移除”再点“粘贴 Key”，下面展开输入框和去拿 Key 的链接。⌘F 搜“字号”回车。书页拖字号，预览总是整行截断。

第十二版：目录 · 设置 · 样张 11-03

还是三块，但三块是一张底：左边是一页真的目录（章、页名、点线、页码），中间是设置，右边那张纸就放在设置旁边、和第一组对齐，不再是另一栏。只有书页、外文、声音三页有这张纸；别的页没有纸，窗口自己收窄，像 Mac 自带的设置窗口换页时那样。搜索挪到窗口右上角，搜的是每一项设置，回车直接跳到那一行、那一行亮一下。按钮换成不描边的软药丸。书伴不用先选再点再贴：复制了 Key 回来，打开这页就看到“用它”；在这页任何地方按 ⌘V 也行，认得出是哪家。

和现在的 App 一样行、开关、分段、滑杆、纸色都是现在设置窗口里的；侧栏底色、选中那一行浮起来的白底和书架窗口一样。
语阅自己的目录有章、点线和页码（页码是这一页从第几项设置开始），改过的页名后面点一个小点；最底下像书的版权页，“改了几处 · 全部改回”。
可以试点“书伴”，点“用它”；或者点 ChatGPT 的“去拿一个”，等一下剪贴板里就“有”了；也可以真的复制一串 sk-ant-… 在页面上按 ⌘V。按 ⌘F 搜“字号”“key”“备份”，回车。在书页和通用之间来回点，看窗口收放。

第十一版：设置窗口（第三稿） 11-03

从 Loop 只借两点：一行一样、排得很齐；只在需要的地方放预览。别的都是语阅自己的：窗口外壳和书架窗口一模一样（同一块浮起来的侧栏、同一种行和开关）；侧栏是一页目录，分“卷一 读、卷二 听……”，每页后面有页码，选中哪页，一条书签丝带从顶上垂下来停在那一行；右边每一页像书的一页：页眉、衬线大标题、一句话说明、页码、末尾“完”。只有书页、外文、声音三页旁边夹一张样张（盖一个小小的“样”字），其余页不放预览、只有一栏。改过的页，目录上那一行前面点一个小点，侧栏底下写“改了几处 · 全部改回”。Key 不弹窗，就在那一行底下展开一个大框。

和现在的 App 一样外壳、侧栏、行、开关、分段、滑杆、按钮都是现在书架窗口和设置窗口里的那几样，颜色只有纸色和墨蓝。
语阅自己的目录和页码、垂下来的书签丝带、页眉页脚、盖“样”字的样张、改过的页在目录上点一个点——都从“书”来，不是别的软件的样子。
可以试点目录里每一页；书页拖字号、行距，换纸、换字体，翻页换“上下滚”样张会翻一下；外文换级别；声音换人会真的念；书伴点“粘贴 Key…”再点“粘贴”；改几样以后看目录上的小点和底下“全部改回”；搜“key”“暗”“备份”。

第十版：照 Loop 的设置 11-03

看了 Loop 的源码（它用作者自己的 Luminare 框架）：三栏、半透明的窗口——左边分组侧栏，每样一个彩色小方块；中间窄窄一列，设置放在圆角的分组里，一行一样，开关、菜单、滑杆都很小很齐；右边一大块是自己会动的预览，每隔一秒演给你看；要填东西（Key）时在窗口里弹一张圆角卡。语阅照这个来，侧栏带一点你觉得有趣的“目录”味道：分组是“一 书页、二 听……”，右边写着页码。

右边一直在演纸：白天和夜里自己来回换；翻页：每两秒翻一页，换成“上下滚”就往上推；声音：书在念，亮的那句跟着语速走；外文：标出来的词一个个亮一下，拖级别就少几个；书伴：连上以后它对选中的那句自己打字回答；同步：Mac 上翻一页，另两台跟上。
中间又小又齐每样只占一行（34 高）：开关在右、菜单在右、滑杆名字和数字一行、滑杆一行。说明只在分组下面一行灰字。右上角的按钮能把预览收起来，窗口变窄。
可以试点左边每一项；拖字号、行距；纸换“夜间纸本”；翻页换“上下滚”、动画拖到“快”；声音换“美佳”（会真的念）；外文拖级别；书伴点“粘贴 Key…”，弹卡里点“粘贴”、完成；存储点“清掉”，圆环变短；外文的词典能拖着排。

第九版：五个方案 11-03

五个方案，思路各不一样，每个都做到能玩：点上面的卡片切换。A、B、E 是在读书窗口上直接改（书在后面跟着变），C、D 是一个新的设置窗口。下面写着每个的想法、好在哪、代价是什么。选一个，或者说哪个的哪部分要；都不行，就不改了。

第八版：海报墙 11-03

打开设置，是八张海报：字、纸、夜里、声音、外文、书伴、同步、空间。每张只说一件事，现在是什么样就画成什么样。点一张，它从原地长成整个窗口；上面是这一样本身（一个大大的“永”、一整张纸、一张会说话的脸、一个大单词），下面浮着一条控件；按 esc 它缩回墙上原来那格。直接打字就能找，对不上的海报淡下去，回车打开。

可以试：点“纸”，再点下面的纸样，新纸从你点的地方漫开；点“声音”，点下面的人，电脑真的用那个声音念，脸外面一圈圈在动；点“外文”，换级别，大单词换成那一级的词；点“书伴”，按 ⌘V（或点虚线框），认出、核对、连上，它跟你打招呼；点“空间”，清掉，数字往下数。

第七版：一页滚到底，预览跟着你走 11-03

第六版好玩但不方便：要从一段话里找词、数字要“知道能拖”才会拖、点开才看得到有哪些选法。这一版先按“用的人要做什么”来排：所有设置在右边一页摆出来，选项都看得见，不藏手势；左边的预览跟着你滚到哪一段，就变成哪一段（书页 → 正在念的书 → 注了中文的英文 → 书伴 → 三台设备……）；每段标题下留着第六版那句话，一眼看到现在是什么样；每改一次，下面冒一条“撤销”。顶上搜索认同义词（打“暗”“大”“念”“api”试试）。

第六版：设置就是一段话 11-03

没有分页、没有开关、没有滑杆。整个设置窗口是一张纸，纸上写着一段话，写的就是你现在怎么读书、怎么听书。蓝色的词都能改：数字按住左右拖（或者滚轮），别的词点一下，别的选法在它上下排开。这段字本身就照你的书页排，改字号它就变大，换纸整张纸就换。选声音时，这台电脑真的用那个声音把这句话念出来。

为什么是一段话开关列表回答的是“这个功能开没开”，一段话回答的是“我现在是怎么读书的”。一眼读完就知道全部状态，不用翻页；改的时候也是在改一句自己的话。
怎么保证好用每个能改的词都是同一个样子（蓝、带下划线），数字是虚线，一看就知道能拖。点开的选法正好压在原位上，上下键、回车、Esc 都能用；Tab 能一个个走过去。右上角“改了几处 · 全部改回去”。⌘F 找一句，别的句子淡下去。
真的做起来Mac 上是一个 SwiftUI 文本视图，词是 Text 里的可点区域；拖数字用 DragGesture；“念出来”就是现在的朗读引擎念这一句。iPhone 上一样是一段话，数字改成上下拨。英文界面写成一段英文。

第五版：每一样都有一个活的预览 11-03

只做一个方向，把它做细。顶上一排 7 样（滑块跟着滑），左边是这一样真的样子：正在念的书页、一页注了中文的英文书、会开口的书伴、三台停在同一页的设备、一条用量。右边是大一号的控件，改什么左边当场变。没有比喻、没有第二层，最多点一下。下面的窗口全都能玩：换纸、拖滑杆、点声音、拖级别、点词、点“粘贴”、点“现在同步”、点“清掉”。

发散：五个完全不同的方向 11-03 第四版

第三版是一个“好用的总览”，还是在“设置窗口里放什么”这个框里想。这里从根上换问题：设置一定要是一个窗口吗？一定要按“外观、阅读、朗读”分吗？一定要你自己去找吗？五个方向各换掉一个前提，每个窗口里都能点。它们可以拼起来用。

换掉的前提甲：设置得是一列列控件 → 设置是桌上的东西。乙：按种类分 → 按时间和场合分。丙：设置得在设置窗口里 → 在书上。丁：你得自己去找 → 它来找你。戊：你得懂术语 → 只回答问题。
可以怎么拼（我的倾向）丙 管书页（日常改字号纸色都在书上）＋ 乙 管“什么时候用哪套”＋ 丁 当设置窗口的首页（有事说事，没事一句一切正常）＋ 第三版的总览当“全部设置”。甲 和 戊 更适合第一次打开的引导。
都不变的⌘K 能搜到每一行；控件都是大一号的系统控件；减弱动态效果时只淡入淡出；没设情景、不按 ⌥ 的人，看到的和现在一样能用。

整个窗口重做 11-03 第三版

前两版都还是“左边一列目录、右边一列开关”，只是换了排法。这一版把这个样子拿掉：打开设置先看到一张总览，每张卡是那一样现在的样子（真的书页、能点的声音、用量）；点卡片放大进去，左边是活的东西、右边是检查器，边看边改。顶上多一个情景：一套书页 + 声音，到点、戴耳机、开英文书时自己换。下面的窗口能点：卡片、‹ 总览、情景、纸、字体、声音卡，字号行距边距的滑杆是真的能拖。

和现在比，变了什么现在 10 个分页、一列列开关，看不出改了以后书长什么样，要开一本书才知道。
改后 没有分页。总览 8 张卡，点进去一层就到；书页、声音这两样边看边改。
为什么不会难用最多点一下就到任何一样；⌘K 能搜到每一行；esc 或“‹ 总览”回来；控件都是大一号的系统控件（滑杆、开关、28 高的按钮、30～46 高的输入框）；同步、存储这种没什么可看的，点进去还是普通的列表。
“默认”和“这本书”不再分两处现在 设置里改的是默认，Aa 里改的是这本书，常常改了不生效。
改后 书页下面一句“改的是：这个情景 / 所有书 / 只这本书”，读书窗口的 Aa 卡片也是同一套。
情景（可以晚点做）白天读、夜里读、通勤听、读英文，各存一套纸、字、声音、语速。到点、戴上耳机、打开英文书时自己换；没设情景的人只看到一个“默认”，跟现在一样。要动核心里的设置存法，所以可以先做总览 + 书页 + 声音 + Key，情景放下一步。
动效点卡片：卡片放大成整页（Mac 上用 matchedGeometryEffect，350 毫秒、不回弹）；回总览时缩回那张卡。换情景：卡片里的纸色、声音淡入换掉。都照 M0 那四档节奏，开了“减弱动态效果”只淡入淡出。
四个想法去哪了第二版的 ① 说一句就改 → 顶上的 ⌘K；② 声音试衣间 → “声音”这页；③ Key 只在一处粘 → “服务与 Key”这页；④ 在哪用就在哪改 → 读书窗口 Aa 卡片和书页这页是同一套。

超前一点：四个想法 11-03 第二版

你说要更超前、又不能难用。下面四个想法都放在左侧栏窗口里画，可以一起要，也可以只挑几个。普通的侧栏、搜索照样在，新东西都是“多一条近路”，不会把熟悉的路堵上。

每一页都适用的

说明只写一句现在很多行的灰字是两三行的长句，读起来像说明书。改成一句说清它管什么；“去哪儿拿 Key”这种步骤换成链接。
只是说明的东西不占一行没有开关、没有按钮的行（导入方法、快捷键、书库路径、专注模式）改成卡片下面的一行注，或者写在段标题右边。

2026-11-03 · 设置为什么难用，怎么改

下面九页的“改后”只解决了每页内部的排法。这里是整个窗口的问题。最后一节是你圈的那块：朗读页右边那一栏，三种做法。

1 · 分页太多，名字分不清现在 顶上 10 个分页挤在一排。外观 / 阅读、朗读 / 书伴 / 外文，要点进去才知道某个开关在哪一页。
改后 左边一列侧栏，按“看 · 读 · 听 · 帮手 · 数据”分组，名字下面能放更多页（以后的播客、分角色声音）也不挤。
2 · 找不到某个设置现在 没有搜索，只能一页页翻。
改后 侧栏顶上一个搜索框（⌘F）：打“Key”“声音”“缩进”，列出是哪一页哪一行，点一下跳过去、那一行黄底闪一下。
3 · 控件太小，输入难现在 按钮、输入框都是 22 高、11 号字，Key 框只有 90～200 宽，挤在右边。
改后 全窗口一档：按钮 28、输入框 30、13 号字；要打字的框占满一整行，不再挤在右栏。
4 · 窗口太矮，长页要滚现在 窗口最高 560，同步、外文、数据都要在里面滚。
改后 侧栏窗口能拉高、拉宽，默认 880 × 640，记住你拉的大小。
5 · 别处点不进来现在 读书窗口 Aa 里、书伴面板里遇到要设置的，只能自己打开设置再找。
改后 这些地方的“设置…”直接打开到那一页那一行（比如书伴没接上 → 书伴页的服务商）。
6 · 每页里放什么照下面九页的“改后”：说明只写一句、只是说明的不占一行、数字在右边、能删的不靠右键、去掉播客页。这些不变。
