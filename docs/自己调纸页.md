# 自己调纸页（颜色、纹理、背景图）

对比图：语阅 · 自定义纸页（画布第二轮）。

## 已经做好的（第一轮）

- 五张预设后面接着“我的纸”，最后一个“＋ 新建”；排不下左右滑。
- 调纸：底色（八个常用色 + 任意颜色）、文字（自动配 / 自己选）、版式（像素白 / 像纸本）、纸纹开关；字太淡会提醒。
- 调的时候书页跟着变；“完成”才存，“取消”或直接关掉都还原。
- 右键 / 长按：调颜色、复制一张、删除。跟着设置同步。

## 这一轮要加的

### 1. 调纸分三页：颜色 · 纹理 · 图片

最上面一排三个键切换，下面的“文字”“版式”三页共用。

- **颜色**：和现在一样。
- **纹理**：无、细颗粒、宣纸、亚麻、牛皮纸。纹理是程序画出来的，不是图片：不占空间、不用下载、没有版权问题，换底色时纹理跟着变色。现在的“纸纹”开关并进这里。
- **图片**：
  - 选照片（手机用系统的照片选择器，不要相册权限；Mac 选文件）。最近用过的图排在旁边，点一下就换。
  - **淡化**：一层和纸同色的薄纱盖在图上。选好图后自动定到“字刚好看得清”，往左拉图更浓（字看不清时照样变红提醒）。
  - **模糊**：默认轻轻糊一点，图的细节不跟字抢。
  - **铺满 / 平铺 / 调位置**：铺满时自动裁；“调位置”可以拖图，选手机竖屏和 Mac 横屏各露哪一块。
  - 字色、灰字、高亮这些颜色从“淡化后的图”的平均颜色算，和纯色纸一样自动配好。

### 2. 加图要方便

- Mac：把图片从访达 / 照片拖到书页上，松手就换好，调纸自动打开在“图片”；也可以复制图片后在书页上按 ⌘V。
- 手机：Aa → ＋ → 图片 → 选照片。
- 从别的 App 分享一张图给语阅，出现“用作纸页”。

### 3. 背景图的规矩

- 只用于这本书：和别的排版一样，可以单独给某本书换图。
- 墨水屏模式下不显示图，只留纯色和纹理（墨水屏刷图慢、灰度难看）。
- 朗读、只听、沉浸阅读都不影响图。
- 夜里：图片纸也可以是深色的——选了暗的图，薄纱自动变成深色、字变浅。

## 用户成本和其他因素

| | 说明 |
|---|---|
| 存储 | 导入时把图缩到长边 2560 像素、压成 JPEG，一张约 0.3–0.6 MB。原图不留。 |
| 同步 | 图片和书文件一样放进用户自己的同步文件夹（WebDAV / Google Drive），不走我们的服务器，没有云费用。另一台设备先显示同色纯色纸，图下载到了再换上。关掉“设置”同步时图也不传。 |
| 耗电 / 流畅 | 图在书页下面单独一层，整本书只画一次；翻页只动文字。低端 Android 按屏幕大小解码，不吃内存。 |
| 隐私 | 图只在用户设备和用户自己的网盘里。 |
| 版权 | 内置纹理是程序画的，不带任何图片素材。用户自己的照片只给自己用。 |
| 删除 | 删掉一张图片纸，图片文件 30 天后清掉（和删书一样，可以撤销）。 |
| Windows | 1.0 不做 Windows 版。纸页的数据（颜色、图片文件、设置）放在共用的核心里，以后有 Windows 版直接能用。 |
| Android | 和 iPhone 一样的三页；Android 没有系统取色盘，用我们自己的“色相 / 浓淡 / 明暗”三条滑杆。 |

## 怎么做（给开发看）

- 核心：纸页记录加 `texture`（无 / 颗粒 / 宣纸 / 亚麻 / 牛皮纸）和 `image`（图片文件名 + 淡化 + 模糊 + 铺法 + 位置）；导入图片、算平均色、算“刚好看得清”的淡化程度都在核心里，三个平台一样。
- 书页：网页那层背景变透明，图放在原生的一层里（固定不动的话，翻页时只有文字在动）。
- 同步：图片按内容起名 `<hash>.paper.jpg`，和书文件同一套上传 / 下载。

## 需要你确认的

1. 翻页时背景图：**A 图不动、只有字翻**（推荐），还是 B 图跟着这一页滑走。见画布“待定 1”。
2. Mac 上调纸放哪：A 还在 Aa 小卡片里，还是 **B 从书旁边滑出一栏**（推荐）。见画布“待定 2”。
3. 内置纹理先做这五种（细颗粒、宣纸、亚麻、牛皮纸 + 无）够不够，要不要别的。
4. 要不要几张内置的风景 / 花草图片？要的话得找能商用的图（或我们自己拍、自己画），会让安装包大几 MB。我建议先不带，靠纹理 + 用户自己的照片。
