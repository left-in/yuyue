**外文**

6. **单本书简繁转换（OpenCC）**：没做（第四节第 2 条你还没确认做不做）。

**漫画**

**笔记导出**

## 三、原型里没画、但上架必须有的

这些不是功能，但没有就上不了架，或者上了会被差评：

1. **隐私说明网页**：App Store 和国内安卓商店都要一个能打开的隐私政策网址。没有服务器，就放在免费的 GitHub Pages 上，一页纸，内容就是 App 里"隐私说明"那段。
2. **苹果的隐私清单（PrivacyInfo）**：现在没有，没有它提交会被退回。语阅不收集任何数据，清单里写"不收集"，再声明用到的几个系统接口（读文件时间、可用空间等）。
3. **各种"没东西 / 出错了"的画面**：原型画了正常情况，没画这些：
   - 书打不开（文件坏了、有 DRM 加密）
   - 权限被拒（语音识别、本地网络）后怎么重新打开
   - 空间不够、下载声音模型中途断网
   - 搜索、笔记、生词本一条都没有时
   我照原型的样式补上，做完给你看截图。
4. **第一次打开的引导**：原型有"先有书可读、可听"，要补的是：同意隐私说明（国区要求首次打开弹出）、通知和专注模式的说明放在用到的时候再问，不一次问一堆。
5. **读屏（VoiceOver / TalkBack）和大字体**：现在只有一部分按钮有读屏说明。苹果审核不强制，但读书软件用读屏的人不少，补齐。
6. **英文界面**：现在只有中文。如果要上海外商店，至少要英文界面。下面问你。
7. **崩溃怎么知道**：没有服务器，就不接第三方统计。用苹果自带的（App Store Connect 里能看崩溃）和 Google Play 自带的，用户不用做任何事。
8. **商店素材**：图标已有。还要截图（iPhone、iPad、Mac 各一套）、一段介绍、关键词、年龄分级问卷。我来写介绍和截图，你挑。
9. **"打赏"内购**：Tips.storekit 已有，要在 App Store Connect 里建好同名商品。国内安卓商店的打赏走不了 Google 支付，Android 国内版先不放打赏。

## 四、Android：从头写界面

Rust 核心和书页是三个平台共用的，这两块不用重写。要写的是 **全部界面**，照原型里 "Android 上一模一样，只换系统那一层" 那几页：

- 书架、读书、听书（Media3：通知栏、锁屏、耳机按键、Android Auto）、笔记、漫画、PDF、搜索 · 问、我的和设置、同步、快照、Wi‑Fi 传书
- Android 独有的：音量键翻页、墨水屏模式、系统返回手势和预测式返回
- 词典用内置 ECDICT（脚本已有）；翻译在海外手机用 ML Kit，国内手机用自带 Key
- PDF 取字：系统的 PdfRenderer 取不了字，要接 pdfium

工作量大约是 Apple 那边的七成（Mac 专有的窗口、菜单不用做）。

**要先解决的事**：
1. 开发工具装到外置盘 T2214（系统盘装不下）。
2. 没有 Android 手机，模拟器能先顶着，但手感（翻页、滑动）必须真机看。TECH.md 第十七节建议的"一台国产安卓手机（没有谷歌服务的）"现在要准备了。

## 五、Windows

TECH.md 定的是 WinUI 3。**WinUI 3 只能在 Windows 电脑上编译和运行**，这台 Mac 上做不了：没法编译，也没法看效果。

我的建议：**1.0 不做 Windows**，先把 iPhone、iPad、Mac、Android 上架。等你有一台 Windows 电脑（或者 Mac 上装 Windows 虚拟机，要再占约 60 GB，只能放外置盘），再开始。
